# 设计与来源

参考网站：[SODA / 苏打的个人网站](https://www.sodasai.com/)。提炼日期为 2026-11-21；后续 Skill 更新以本公开仓库为准。

这是从现有个人站提炼的轻量起步实现，不是原站完整源码镜像或像素级复刻。内容架构与基础设计变量来自来源站的产品文档、主题规范、排版规范和实际代码；未打包原始内容与素材。

## 保留的结构

「经历塑造观点 → 观点指导方法 → 方法沉淀作品」是一条可以解释个人发展过程的路径。

| 房间 | 对读者的问题 | 适合材料 |
| --- | --- | --- |
| Story / 来时路 | 你怎么走到今天？ | 真实成长章节、转折、选择 |
| Orbit / 思考轨道 | 你关心什么、如何判断？ | 观点、问题、观察与变化 |
| Digest / 实践沉淀 | 你怎么做事？ | 做法、实验、复盘与限制 |
| Artifact / 创造物 | 你做出了什么？ | 作品、产品、项目、演示与证据 |

这四个入口不要求同等内容量。作家、摄影师、工程师、研究者都可以按自己材料改名或隐藏部分房间。

## 视觉基础

- 浅色纸面 `#f3efe5`，次级纸面 `#ebe5d8`，深墨 `#12110f`，点缀橙 `#d84a1a`。
- 深色底 `#090a0b`，浅墨 `#f1eee7`，次级文字要保持对比；主题必须覆盖所有页面和弹窗。
- 展示名使用衬线字体与较大字号；正文用系统无衬线字体，避免第三方字体请求。普通章节标题约 32–52px，正文至少 16px，标注不低于 12px。
- 用留白、网格与细线划分段落，避免每段都套圆角卡片。四个房间是入口，作品是证据，文字是持续记录。
- 没有授权头像时，显示 CSS 抽象轨道；没有作品图片时，使用编号式构图。不能拿原作者肖像代替用户。

## 从原站修复中继承的约束

- 中文短句能完整呈现时不人为压成窄列；手机空间不足时自然换行。
- 英文按完整单词换行；不要把中文的强制单行规则套到英文。
- 不用固定高度裁掉标题或摘要，不用极小字号或禁止缩放掩盖问题。
- 作品说明的标签与正文在窄屏改为上下排列。
- 全站主题跨路由、刷新保持；本地存储不可用时也能阅读。
- 动态只增强体验，`prefers-reduced-motion` 下关闭；内容不等待滚动观察器才出现。
- 背景音乐是原作者的个性选择，且授权不能自动转给其他人，因此不随模板分发。

## 使用与归属

本仓库的 Skill 和起步代码供任何人参考、修改，用于搭建自己的个人网站。原站人物、内容、作品和素材不随本仓库提供；不得宣称它们属于使用者。Next.js 与 React 的第三方许可证继续适用。
