# 工程与验收

## 环境与生成

生成器只依赖 Node 内置模块。模板沿用来源站的 Next.js / React 技术栈，使用 Next.js 16.4.6、React 19.2.4、TypeScript、ESLint，不加入 UI 库、付费服务或数据库。来源站的 Next.js 16.3.0 在提炼时的依赖审计中存在严重漏洞，因此只为本模板采用修复版。所附锁文件记录本次验证的完整依赖；后续维护者应关注官方安全公告，升级后重验，不机械采用 `latest`。

生成器不自动初始化 Git，以免越过建站者的工作区规则。需要版本记录时，在生成站点自己的目录建立基线，再在工作分支个性化；发布与推送依照建站者授权执行。复制到新机器后，站点可以不依赖 Skill 或原作者仓库继续运行。

生成后：

```bash
npm ci
npm run lint
npm run build
npm run typecheck
npm run start
```

首次没有锁文件时使用 `npm install`。自有图片先复制到 `public/images/`，构建会核对图片是否存在。生成目录已存在时停止并选择新目录；不清空原目录、不强制覆盖。

## 验证清单

| 范围 | 实际动作 |
| --- | --- |
| 内容 | 姓名、介绍、链接属于用户；没有原作者照片、文章、二维码与音乐 |
| 导航 | 首页 → 作品/文字 → 文章 → 首页/联系；默认没有四房间入口，未启用的档案路由返回 404 |
| 排版 | 1440px、390px，中英文，浅色/深色；检查文本实际绘制与横向溢出 |
| 阅读 | 切换分类，打开、滚动、展开、Esc 关闭，焦点回到触发按钮；独立文章可访问 |
| 状态 | 主题跨页面与刷新保持；存储被浏览器禁止时页面仍可用 |
| 空状态 | 无作品/文章/联系方式可阅读；不会生成失效假按钮 |
| 构建 | 配置、lint、生产构建、类型检查均通过 |
| 安全 | 文本按 React 转义；外链仅 HTTPS；无凭据、密钥、追踪或生产数据 |

如果不能完成某项，交付时明确标注未验证，不把构建通过当作视觉验收通过。

## 搜索与分享

默认 `publish=false`，robots 禁止索引、sitemap 为空，页面带 noindex。部署平台的 Preview 也应保持此设置。noindex 不是私密访问控制。

只有取得正式发布授权、替换演示内容并设置真实 HTTPS `siteUrl` 后，才把 `publish` 改成 `true` 并重新构建。每个公开页面需要正确 canonical、标题、描述；分享图由代码生成，不读取原作者素材。首页 canonical 不得错误继承到内页。部署后逐项读实际 HTML、robots、sitemap、分享图和 404。

无表单、账户、数据库与付费 API 时，不凭空增加后台或数据库检查。后续实际引入这些能力时，另行明确数据模型、权限、隐私、预算与验收，不把个人站模板当成已完成的业务系统。
